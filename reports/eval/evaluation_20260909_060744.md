## RAG Architecture (Post-Enhancement)

### Before (Template-only)
```
User question → Regex detection → Retrieve top-k → String template → Answer
```

### After (LLM + Template fallback)
```
User question → Regex detection → Retrieve top-k → LLM available?
                                                    ├── Yes → qwen2.5:1.5b → Natural answer
                                                    └── No  → Template fallback
```

### Key Improvements
1. **LLM generation** via Ollama + qwen2.5:1.5b for natural-language answers
2. **Graceful fallback** to templates when Ollama is unavailable
3. **Role-skill inference** for questions where retrieved results lack skill data
4. **Docker-aware path resolution** for both RAG index and analytics data
5. **OLLAMA_HOST environment variable** support for containerized deployments

## Recommendations

- All models performing within acceptable ranges. Consider expanding the gold set for more robust evaluation.
- RAG retrieval MRR improved from 0.894 to 0.967 with TF-IDF index refresh.
- LLM generation adds significant quality for qualitative questions (skill advice, career guidance).
- Consider upgrading to qwen2.5:3b or qwen2.5:7b for more complex multi-hop reasoning.
- Monitor Ollama availability in production; template fallback ensures zero downtime.
